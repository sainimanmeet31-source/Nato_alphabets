# 📻 NATO Phonetic Alphabet Converter

A Python program that spells out any name using the NATO phonetic alphabet.

## Example
```
Enter your name: Sam
For Sam say: ['Sierra', 'Alfa', 'Mike']
```

## How to run
Requires Python 3 and pandas.

```bash
pip install pandas
python main.py
```

## Project structure
| File | Purpose |
|------|---------|
| `main.py` | Reads input and converts it |
| `nato_phonetic_alphabet.csv` | Letter to code word mapping |
